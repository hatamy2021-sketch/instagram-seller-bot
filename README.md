# ربات تلگرام فروش خدمات اینستاگرام

🤖 ربات خودکار برای فروش خدمات اینستاگرام (فالو، لایک، بازدید و...) در تلگرام

## ✨ ویژگی‌ها

- ✅ احراز هویت کاربر (شماره تلگرام و شماره کارت)
- 💰 سیستم موجودی و پرداخت
- 📦 مدیریت سفارش‌ها
- 🛡️ پنل ادمین
- 💬 سیستم پشتیبانی
- 📊 آمار و گزارش‌ها
- 🌍 پشتیبانی برای چندین خدمت

## 🚀 نصب و راه‌اندازی

### 1. نیازمندی‌ها

```bash
python 3.8+
MySQL Server
```

### 2. نصب بسته‌ها

```bash
pip install -r requirements.txt
```

### 3. تنظیم پایگاه داده

```bash
python setup.py
```

### 4. تنظیم متغیرهای محیط

فایل `.env` را ایجاد کنید:

```bash
cp .env.example .env
```

سپس فایل `.env` را ویرایش کنید و موارد زیر را وارد کنید:

- `BOT_TOKEN`: توکن ربات تلگرام (از @BotFather دریافت کنید)
- `ADMIN_ID`: شناسه تلگرام ادمین
- `DB_PASSWORD`: رمز عبور MySQL

### 5. اجرای ربات

```bash
python bot.py
```

## 🏠 نصب روی cPanel

### 1. آپلود فایل‌ها

1. به cPanel وارد شوید
2. File Manager را باز کنید
3. پوشه `public_html` یا `home/yourdomain` را انتخاب کنید
4. تمام فایل‌های ربات را آپلود کنید

### 2. نصب بسته‌ها

1. SSH را باز کنید
2. به فایل‌های ربات بروید:
```bash
cd ~/public_html/instagram-seller-bot
```

3. بسته‌ها را نصب کنید:
```bash
pip install -r requirements.txt
```

### 3. تنظیم MySQL

1. به cPanel برگردید
2. MySQL Databases را انتخاب کنید
3. پایگاه داده جدید ایجاد کنید
4. کاربر جدید ایجاد کنید
5. اطلاعات را در `.env` وارد کنید

### 4. اجرای ربات

1. SSH میں:
```bash
nohup python bot.py > bot.log 2>&1 &
```

2. یا از طریق cron:
```bash
* * * * * cd ~/public_html/instagram-seller-bot && python bot.py
```

## 🔒 نکات امنیتی

⚠️ **مهم:**

1. **توکن ربات**: هرگز توکن ربات را در کد سرچشمه قرار ندهید. از `.env` استفاده کنید.
2. **رمز عبور**: رمز عبور پایگاه داده را مطمئن کنید.
3. **دسترسی**: فقط ادمین باید به پنل ادمین دسترسی داشته باشد.
4. **HTTPS**: برای پیام‌های حاوی اطلاعات حساس، از HTTPS استفاده کنید.

## 🐛 عیب‌یابی

### خطای اتصال به پایگاه داده

1. اطمینان حاصل کنید که MySQL در حال اجرا است
2. اطلاعات پایگاه داده در `.env` را بررسی کنید
3. پایگاه داده را دوباره ایجاد کنید: `python setup.py`

### ربات پاسخ نمی‌دهد

1. توکن ربات را بررسی کنید
2. لاگ‌های ربات را بررسی کنید: `tail -f bot.log`
3. اطمینان حاصل کنید که ربات در حال اجرا است
